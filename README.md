This is an self created discord rocket league queueing bot. Fully functional but still a WIP as I add new features as suggestions arise.

Versatile in modes such as 1v1, 2v2 and 3v3, with an ELO system for all players
2v2 and 3v3 have options to choose between random, balanced and drafted teams
profiles are created for all players as they enroll in the bot. To play a player much be enrolled
/help gives a list of all commands and what they do
I run this bot off of my own pc though powershell but it could very well be hosted on a site or something.
